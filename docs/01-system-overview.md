## Назначение и контекст

ППО «Территория» — информационная система ведомственного назначения в предметной области Федеральной миграционной службы. Доступные материалы описывают несколько функциональных направлений, поддерживающих процессы миграционного учёта и оказания государственных услуг.

Документированная архитектура предусматривает централизованный и распределённый варианты развёртывания, серверы приложений и баз данных, рабочие места с тонким клиентом при централизованной модели, а также обмен данными с внешними системами.

В этом репозитории ППО «Территория» рассматривается как самостоятельная система. АРМ «Дискриптор», «Дешифратор» и UMMS описываются в портфолио как отдельные системные границы; совместное размещение материалов не означает единую исполняемую или эксплуатационную архитектуру.

В исходных материалах упоминаются 17 функциональных модулей, однако доступные описания пока не позволяют восстановить полный подтверждённый перечень по каждому модулю. Полный состав необходимо сверить с первичной технической документацией.

## Purpose and context

PPO Territory is an enterprise information system in the Federal Migration Service domain. The available materials describe multiple functional areas supporting migration-related registration and public-service processes.

The documented architecture includes centralized and distributed deployment options, application and database servers, thin-client workstations in centralized deployments, and external data exchanges.

This repository documents PPO Territory as a standalone system. ARM Descriptor, Deshifrator, and UMMS are maintained as separate system boundaries in the related documentation hub; their presence in the same portfolio does not imply a shared executable or runtime architecture.

The source materials refer to 17 functional modules, but the available descriptions do not yet provide a complete verified module-by-module inventory. Confirm the full list against primary technical documentation.

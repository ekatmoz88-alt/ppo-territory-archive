# ППО «Территория» — исторические требования к платформе

[Русский](#ru) | [English](#en)

<a id="ru"></a>

В доступных технических материалах упоминаются следующие исторические платформы и компоненты:

- Microsoft Windows XP, Vista, 7 и 8.
- Oracle Linux 5.6.
- Debian 6.
- Java Runtime Environment 6.
- CryptoPro CSP 3.6 R2.
- Технологии баз данных Oracle в общем контексте системы.

Эти версии отражают исторические требования и являются устаревшими. Их нельзя рассматривать как рекомендации для современных развёртываний.

Наличие требования к определённой технологии не доказывает, что конкретная версия была установлена на каждой площадке. Фактические конфигурации, уровни обновлений и региональные настройки необходимо подтверждать эксплуатационными записями или свидетельствами из системы.

<a id="en"></a>

The available technical materials mention the following historical platforms and components:

- Microsoft Windows XP, Vista, 7 and 8.
- Oracle Linux 5.6.
- Debian 6.
- Java Runtime Environment 6.
- CryptoPro CSP 3.6 R2.
- Oracle database technologies in the broader system context.

These versions reflect historical requirements and are obsolete. They must not be treated as current deployment recommendations.

A technical requirement does not prove that a specific version was installed at every site. Actual inventories, patch levels and regional configurations require operational records or system evidence.

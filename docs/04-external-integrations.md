В доступных материалах указаны семь направлений обмена:

| Внешняя система / сервис | Описанный обмен |
|---|---|
| ЦБД УИГ | Сведения о визах, выдворении и депортации |
| ПРИУР ГАС «Выборы» | Экспорт данных и отчётная форма 1.1 РИУР |
| ГИАЦ ГУ МВД | Загрузка ответов; сведения Криминал-И и об административных правонарушениях |
| Росстат | Формы 12-П и 12-В |
| ЗАГС | Загрузка записей о рождении и смерти |
| АС «Российский паспорт» | Нормализация пути экспорта, включая замену символа `/` на `\\` |
| СПО «Сервисный концентратор» | Направление интеграции, связанное со СМЭВ, ЕПГУ, ФНС и ДКС МИД |

Таблица фиксирует направления обмена, упомянутые в доступных материалах. Она не подтверждает доступность действующих конечных точек, версии протоколов, способы аутентификации, схемы сообщений или текущий эксплуатационный статус интеграций.

The available materials identify seven integration directions:

| External system / service | Described exchange |
|---|---|
| ЦБД УИГ | Visa, expulsion and deportation-related information |
| ПРИУР ГАС «Выборы» | Data export and reporting form 1.1 РИУР |
| ГИАЦ ГУ МВД | Loading responses; Криминал-И and administrative-offence information |
| Росстат | Forms 12-П and 12-В |
| ЗАГС | Loading birth and death records |
| АС «Российский паспорт» | Export path normalization, including replacement of `/` with `\\` |
| СПО «Сервисный концентратор» | Integration direction involving СМЭВ, ЕПГУ, ФНС and ДКС МИД |

This table records integration directions in available materials. It does not establish current endpoint availability, protocol versions, authentication, message schemas or present-day operational status.
